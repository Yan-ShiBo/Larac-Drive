# CBF-Rover Simulation

This directory contains the ROS 2 and Gazebo adapters used by CBF-Rover
simulation experiments. It intentionally excludes physical-hardware drivers,
certificate synthesis, trained checkpoints, and generated experiment output.

The colcon workspace is in `ros2_ws/`. See `ros2_ws/README.md` for the package
boundaries, scenario-injection contract, and launch commands.
