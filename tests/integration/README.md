# Server-only integration tests

本目录预留给 Python 研究栈与外部模型工件的集成测试。所有测试只在服务器环境运行，本机不执行。

计划覆盖：

- 通过 `CBF_ROVER_ARTIFACT_ROOT` 注入并校验五个外部工件；
- 缺失、哈希不匹配或不兼容工件必须 fail closed；
- 数据集读取、训练入口、检查点加载与实验记录的端到端契约；
- 固定场景、固定随机种子与完整日志下的可复现实验。

当前目录没有可宣称通过的集成测试结果。新增用例后，只有服务器实际执行并保存环境信息、命令、日志和结果，才能记录为通过；集成测试结果也不构成形式化安全证明。
