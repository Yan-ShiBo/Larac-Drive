# Larac-Drive 项目方向

**随机扰动下车辆强化学习控制与可达—规避概率验证系统｜独立开发｜2025.03 至今**

Larac-Drive（原名 CBF-Rover）面向结构化道路中的自适应跟驰、前车急刹与邻车切入。前车的制动强度具有不确定性，自车的加速度与曲率又受到运动约束。项目要回答两个问题：学习策略能否在这些工况下同时改善跟踪、安全与平顺性？当同车道前车随机制动时，能否为特定纵向应急控制器给出可验证的成功概率下界？

本文自 2026-11-12 起作为项目开发方向。以下技术路线和验收目标描述待完成的车辆系统；已有实验及其适用范围见文末。

## 技术路线

1. **车辆模型与策略。** 在道路参考线的 Frenet 坐标系下建立无侧滑车辆运动学模型。策略输出纵向加速度与车辆曲率，分别控制车速和行驶方向。奖励函数同时惩罚跟踪误差和控制变化率。采用 Soft Actor-Critic（SAC）训练横纵向联合控制策略；以智能驾驶员模型（IDM）作纵向跟驰对照，以模型预测控制（MPC）作横纵向对照。涉及横向任务时，需注明 IDM 配用的横向控制器。
2. **在线安全约束。** 针对前车制动不确定性，为纵向安全时距构造鲁棒控制障碍函数（CBF）；针对横向道路边界构造高阶控制障碍函数（HOCBF）。每个控制周期通过二次规划（QP）修正策略动作：在满足约束的同时，兼顾对名义动作的偏离和相对上一周期的指令变化。为低速和 QP 不可行工况设计紧急制动逻辑，单独记录触发条件和结果。
3. **纵向应急控制与概率验证。** 仅针对同车道前车随机制动，建立三维纵向应急控制子系统。先定义状态域、初始集、目标集、危险集及前车制动分布，再以带 PAC 统计误差保证的方法将应急策略近似为多项式控制器。对该控制器构成的闭环，通过平方和（SOS）与半定规划（SDP）求解随机障碍证书（SBC）。依据证书的条件期望下降要求迭代调整控制器系数，每次更新后重新验证，在通过验证的候选中比较可达—规避概率下界。只有状态位于指定域且模型假设适用时，才调用对应的已验证多项式控制器。

这里的**可达—规避事件**是纵向应急闭环从规定的初始集出发，先进入目标集而未先进入危险集。PAC 描述近似误差的统计保证；成功概率下界来自对指定闭环及随机制动模型成立的 SBC 条件。该下界不覆盖整车 SAC 策略、横向切入过程或任意 QP 回退动作。

## 验收目标

| 要回答的问题 | 需要保留的证据 |
| --- | --- |
| 策略能否完成跟驰、应对前车急刹及邻车切入？ | 三类工况的闭环轨迹；在相同初始条件、扰动样本与控制周期下比较 SAC、IDM 和 MPC，分别报告跟踪误差与约束违约率。 |
| 在线约束是否降低违约率，平滑代价是否减小指令波动？ | 分开比较启用／关闭安全约束、使用／移除平滑代价的结果。分别统计安全时距和道路边界违约率，注明分母；报告加速度与曲率的变化率、紧急制动次数和触发原因。 |
| 能否在规定的控制周期内完成计算？ | 在注明硬件与控制周期的条件下，分别报告 SAC 单步推理和 QP 求解耗时，并记录超时或不可行情况。 |
| 纵向应急控制器的证书有多保守？ | 保存通过验证的控制器、SBC、适用域、制动分布和概率下界；在相同初始条件与事件定义下，用独立 Monte Carlo 仿真估计成功率，报告样本数、置信区间及其与下界的差距。 |
